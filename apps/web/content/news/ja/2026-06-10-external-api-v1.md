## 新機能

### 外部 API（読み取り専用）

スクリプト・CLI・ローカル LLM など、ブラウザ以外のツールから自分の旅行データにアクセスできる外部 API を追加しました。現在は読み取り専用で、次のデータを取得できます。

- 旅行の一覧・詳細（日程・メンバーを含む）
- 費用の一覧
- ブックマークリストとリスト内のブックマーク
- 自分が作成した記事

### API キーの発行・管理

設定画面の「API キー」タブから、API キーの発行・一覧表示・削除ができます。キーを発行する際に有効期限（最長 90 日）とアクセスできるデータの種類を選択します。

- キーは発行時に 1 回だけ表示されます。再表示できないため、コピーして安全な場所に保管してください
- 削除するとすぐに無効になります
- パスワードを変更・リセットすると、セキュリティのために発行済みの API キーはすべて無効になります
- ゲストアカウントでは利用できません

### API リファレンス

ログインした状態で `/api/_docs` を開くと、利用できる API の一覧と試し打ちができるリファレンスページを表示できます。

引き続きご意見・ご要望は設定画面のフィードバックからお寄せください。
