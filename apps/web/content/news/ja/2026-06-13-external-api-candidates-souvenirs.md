## 新機能

### 候補とお土産を外部 API で操作できます

外部 API（v1）と MCP サーバーで、新たに候補とお土産を扱えるようになりました。

- 候補（日程に割り当てる前の行き先ストック）の一覧取得・作成・更新
- お土産の一覧取得・作成・更新

これまでどおり削除は外部 API からは行えません。アプリの画面から操作してください。

### アクセス権限について

- 候補は予定と同じ「旅行」のスコープ（`trips:read` / `trips:write`）で操作します。新しいスコープの追加は不要です
- お土産は専用の「お土産」スコープ（`souvenirs:read` / `souvenirs:write`）を追加しました。API キーの発行画面で選べます
- 共有されている旅行で候補を作成・更新するには「編集者」以上の権限が必要です。お土産は、メンバーであれば誰でも自分のお土産を追加・更新できます

MCP サーバーにも対応するツール（`list_candidates` / `create_candidate` / `update_candidate` / `list_souvenirs` / `create_souvenir` / `update_souvenir`）を追加しました。API リファレンス（ログインした状態で `/api/_docs`）も新しいエンドポイントに対応しています。

引き続きご意見・ご要望は設定画面のフィードバックからお寄せください。
