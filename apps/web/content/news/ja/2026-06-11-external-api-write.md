## 新機能

### 外部 API での作成・更新

先日追加した外部 API（v1）で、読み取りに加えてデータの作成と更新もできるようになりました。対象は次のとおりです。

- 旅行の作成・更新と、各日への予定の追加・更新
- 費用の登録・更新
- ブックマークリストとブックマークの作成・更新
- 記事の作成・更新

削除はこれまでどおり外部 API からは行えません。アプリの画面から操作してください。

### 書き込み用のアクセス権限

API キーの発行時に、データの種類ごとに「読み取り」と「作成・更新」を分けて選択できるようになりました。書き込みが不要なキーには読み取りのみを選ぶことで、安全に使い分けられます。

- 発行済みのキーはこれまでどおり読み取り専用のまま動作します。書き込みを使うには新しいキーを発行してください
- 共有されている旅行への書き込みには、その旅行での「編集者」以上の権限が必要です

API リファレンス（ログインした状態で `/api/_docs`）も新しいエンドポイントに対応しています。

引き続きご意見・ご要望は設定画面のフィードバックからお寄せください。
