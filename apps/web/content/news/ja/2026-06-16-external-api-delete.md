## 新機能

### 外部 API で削除ができるようになりました

外部 API（v1）で、データの削除に対応しました。

- 予定、費用、ブックマーク、記事、候補、お土産の削除

旅行自体の削除はセキュリティのためアプリの画面からのみ可能です。外部 API では削除できません。

### アクセス権限について

- 削除には既存の「作成・更新」権限（write スコープ）で対応します。新しいスコープの追加は不要です。API キーの発行画面のラベルも「作成・更新・削除」に更新されています
- 共有されている旅行の予定・費用を削除するには「編集者」以上の権限が必要です。お土産・ブックマーク・記事は、メンバーであれば自分のものを削除できます
- 削除操作は取り消せません。また、存在しないデータの削除は無視され（冪等性）、エラーになりません

API リファレンス（ログインした状態で `/api/_docs`）で各エンドポイントの詳細を確認できます。

引き続きご意見・ご要望は設定画面のフィードバックからお寄せください。
